# PRD Studio Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** User tulis ide proyek → dapat PRD rapi (tujuan, scope, fitur, acceptance, task breakdown) → bisa dipakai buat ngerjain proyek.

**Architecture:** Satu halaman dashboard baru `/dashboard/prd` yang manggil gateway sendiri (`/v1/chat/completions`) pakai model yang user pilih. Alur WAWANCARA DULU (2-3 ronde, maks 3 pertanyaan per ronde, single-idea, paling penting dulu) baru DRAFT — bukan generate sekali tembak. Tanpa tabel DB baru (save di localStorage + export .md). Template PRD Bahasa Indonesia.

**Tech Stack:** Next.js App Router (client page), fetch ke `/v1/chat/completions`, localStorage, markdown render sederhana.

### Task 2: Halaman PRD Studio (wawancara → draft → kritik)

**Objective:** Form + 2-3 ronde wawancara + generate + self-critique → output PRD markdown berkualitas.

**Files:**
- Create: `src/app/(dashboard)/dashboard/prd/page.js`
- Create: `src/app/(dashboard)/dashboard/prd/PrdPageClient.js`

**Wawancara (ikuti decision-questionnaire):** maks 3 pertanyaan/ronde, single-idea, paling penting dulu, tiap pertanyaan ada "kenapa penting" + contoh jawaban + tombol "Gak tau/lewati".
- Ronde 1 (masalah): masalah apa? siapa user-nya? sukses = apa (metric)?
- Ronde 2 (batas): scope IN/OUT, deadline/budget, tech constraint.
- Ronde 3 (fitur kasar): 3-5 fitur impian → nanti dipaksa jadi P0/P1/P2.

**Draft (system prompt ketat):** struktur 9 section (ringkasan, masalah, tujuan+metric, target user JTBD, scope IN/OUT, fitur P0 max 5 + acceptance Given-When-Then, user flow, task checklist per fase, risiko+mitigasi, open questions). Temperature 0.2-0.3. Full transcript wawancara ikut sebagai context (model 1M context muat).

**Self-critique pass (murah, 1 call tambahan):** prompt kedua "kritik draft ini: mana fitur generik? mana acceptance kabur? mana scope creep?" → revisi otomatis. Ini yang bikin beda generik vs bagus.

**Step: Verifikasi** — isi contoh proyek, lewat 3 ronde, pastikan output ada P0 + acceptance + risiko.
